## Project Files

- `sample_emails.md` — Fictional sample emails and manual classification.
- `awareness_tips.md` — Phishing warning signs and prevention tips.
- `FUTURE_CS_Task2_Report.pdf` — Task report and findings.

## Method

Three fictional sample emails were reviewed manually and classified based on the text provided. No real email accounts or email headers were analyzed.

## Limitations

This is a manual, text-based awareness exercise. It is not an automated phishing detection tool, and the classifications do not verify the sender or any links.
